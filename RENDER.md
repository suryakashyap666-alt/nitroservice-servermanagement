# Deploy Nitro Server Manager on Render

This service runs the FastAPI backend with:

- Start command: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
- Health check: `/api/v1/health`
- Persistent moderation data at `/var/data`

## Deploy

1. Push the `ai-backend` folder to a GitHub or GitLab repository.
2. In Render, choose **New > Blueprint** and select that repository.
3. Render detects `render.yaml` and creates the web service.
4. Set `WEB_CLIENT_ORIGIN` to the URL of the web frontend that will call this API.
5. Open the deployed `/docs` URL to test the API.

The Blueprint uses Render's `starter` plan because an always-on service and a
persistent disk are required for reliable moderation state. Render's free web
services can sleep and their local filesystem is temporary.

## Important environment variables

- `NITRO_JWT_SECRET`: generated by Render in the Blueprint.
- `WEB_CLIENT_ORIGIN`: frontend origin, for example `https://your-ui.onrender.com`.
- `NITRO_DATA_DIR`: set by the Blueprint to `/var/data`.

Never commit `.env`, API keys, passwords, or private certificates.
