## 📊 ADAPTIVE LEARNING FEATURES

### **1. Automatic Difficulty Adjustment**
```
Success < 40%:  Easy    (Reduce to build foundation)
Success 40-60%: Medium  (Current appropriate level)
Success 60-75%: Medium→Hard (Ready for challenge)
Success > 75%:  Hard    (Advanced problems)

3 consecutive correct → Difficulty increases
1 incorrect → Difficulty may decrease
```

### **2. Learning Style Detection**
The system learns how each user prefers to learn:

**STEPS** (Step-by-Step)
- Clear sequence: Intro → Foundation → Examples → Practice
- Checkpoint-based progression
- Scaffolded support
- Triggered after: Struggles (low success rate)

**PROBE** (Concept Exploration)
- Conceptual questions first
- Let user discover patterns
- Challenge-based approach
- Triggered after: Success streaks (2+ correct)

**MIXED** (Balanced)
- Combination of both approaches
- Default for new learners
- Adjusts based on performance

### **3. Learning Speed Tracking**
```
EMA (Exponential Moving Average) of performance:
- 0.0-0.4: Slow learner → More time, gentler pace
- 0.4-0.7: Medium learner → Balanced approach
- 0.7-1.0: Fast learner → Accelerated content

Affects:
- Daily study time recommendations
- Problem complexity
- Time between topics
- Challenge difficulty
```

### **4. Subject-Level Proficiency**
Tracks per subject:
- **Success Rate**: % of correct attempts
- **Total Attempts**: How many times tried
- **Correct Answers**: Cumulative correct count
- **Weak/Strong Scores**: Internal indicators
- **Streak**: Current consecutive correct
- **Ready for Challenge**: Boolean for next difficulty

### **5. Emotional Support**
Adapts to emotional state:
```
😢 Sad/Frustrated:
  "💪 Remember: Learning takes time. You're doing great!"
  "Let's take this slow and build understanding."

😊 Happy:
  "✨ Great energy! Let's make the most of it!"
  "Challenge yourself today!"
```
